# SheetDrop Release Notes

## v0.1.0 — 2026-10-12

First SheetDrop distribution packaged from the MIT-licensed SheetAtlas codebase.

### Included

- Local import of `.xlsx`, `.xls`, and CSV
- Cross-file search and row comparison
- Data regions, normalize, and export
- Windows self-contained build packaging
- Privacy policy and attribution documentation
